# imim

换过手机、跨过时区，或从旧硬盘找回的照片，常常会在图库里排错时间。imim 帮你查看和修正拍摄时间、时区与位置，也能将其他设备的照片和视频配对导入为 Apple 实况照片。

这是一个仍在起步的 Mac App。照片在本机处理，不上传到服务器。批量修改前，建议先用几张副本试一下。

## 能做什么

- **浏览照片**：在 Apple「照片」图库与本地文件夹之间切换，网格浏览，双击查看大图与元数据。
- **修正时间与位置**：单张调整拍摄日期、时区和经纬度，也可以在地图上选择位置。位置写入目前支持 JPEG。
- **批量整理**：把选中的照片放进修复会话，分析后按拍摄时间分组，统一调整或逐张修改，之后再导入图库。
- **导入实况照片**：将同名照片与 MOV / MP4 视频配对，在暂存副本中补齐配对信息后导入，保留来源文件。
- **备份与还原**：写回文件前备份，支持还原单张或整个会话。图库修正版作为新照片导入，不直接改写图库原片。

## 开始使用

需要 **macOS 26 或更新版本**，目前发行流程面向 **Apple Silicon**，尚未提供经过验证的 Intel 安装包。界面支持中文和英文。

发行包发布在 [GitHub Releases](https://github.com/Psrit/imim-releases/releases)。下载 ZIP，解压后将 `imim.app` 拖入「应用程序」。

当前采用 ad-hoc 签名，尚无 Apple Developer ID 签名和公证。下载版第一次打开可能被 macOS 拦截；确认来源可信后，可按系统提示到「系统设置 → 隐私与安全性」选择「仍要打开」。

打开后，选择照片图库或本地文件夹作为来源。使用图库时需要照片访问权限，导入修正版需要完整访问。

**修一张照片**：双击打开详情，调整时间、时区或位置。文件夹中的照片可以写回原文件、另存或导入图库；图库照片则导入修正版，成功后再由你决定是否删除原片。

**批量修复**：选中多张照片，点工具栏的魔法棒创建会话，在「批量修复时间戳」页面分析、修改并导入。会话保留暂存文件与备份，方便继续处理或还原。

**导入外部动图**：准备同一文件夹下的同名文件，例如 `IMG_0001.jpg` 和 `IMG_0001.mp4`，在「导入外部动图」中核对配对后导入。目前处理的是分离的照片与视频，不是任意厂商的内嵌动态照片文件。缺少配对标记、需要补写时，静态照片须为 JPEG。

## 格式与写入范围

能预览一张照片，不代表能修改它的所有元数据。RAW 的读取能力也取决于 macOS 对具体相机格式的支持。

| 格式 | 拍摄时间与时区 | 位置 |
| --- | --- | --- |
| JPEG | 可修改，支持补充缺失字段 | 可修改或新增；受保护的厂商元数据可能阻止写入 |
| HEIC / HEIF、PNG | 可修改，支持补充缺失字段 | 只读 |
| TIFF、Sony RAW（ARW / SR2） | 只能覆盖已有且可写的字段 | 只读 |
| WebP、GIF、BMP | 只读 | 只读 |

时间修改尽量保留原始图像数据，但并非所有操作都只是覆盖几个字节：补充 EXIF 字段可能调整元数据结构，JPEG 位置写入可能由系统图像框架重写文件。遇到不能安全写入的格式或字段，应用会报错。

实况照片导入会补写配对信息，并可能重封装视频容器；目前没有通用的视频拍摄时间编辑功能。云端图库比对与照片查重也尚未实现。

## 照片和备份放在哪里

图库原片不会被就地修改。修正版导入成功后，删除原片仍需确认，删除后进入「照片」的「最近删除」。文件夹模式下选择「应用到原文件」会实际写回磁盘文件，写入前保存备份。

修复会话和文件夹备份保存在：

```text
~/Library/Application Support/com.xiaojx.imim/
├── sessions/
└── folder-backups/
```

会话备份用于累计还原，并非每次修改都保存一份独立历史。删除会话也会删除其中的暂存照片与备份；确认不再需要还原后再清理。重要照片仍建议保留自己的独立备份。

照片处理在本机完成。地图功能可能使用系统地图服务；从 iCloud 获取尚未下载的图库原件也可能联网。软件更新检查和下载同样需要网络。

## 软件更新

App 菜单中提供「检查更新…」，设置中可以开启自动检查，默认关闭。更新由 Sparkle 提供，更新包使用 EdDSA 签名验证。

安装包与更新源通过独立的公开分发仓库提供，应用源码仓库保持私有。已有不含更新器的旧版本，需要先手动安装带更新器的版本。Sparkle 签名不会代替 Apple 的签名与公证。

## 反馈

遇到问题可以提交 [Issue](https://github.com/Psrit/imim-releases/issues)，附上 macOS 版本、imim 版本、照片格式和复现步骤。涉及照片时，优先使用去除隐私信息的样本，并说明来源是图库还是文件夹。
